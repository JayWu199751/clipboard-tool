## 一、产品定义

后台记录用户复制过的**文字与图片**，用全局呼出键（默认 `Ctrl+Shift+V`）在光标处呼出一个**不抢焦点的置顶浮层面板**；面板里选中一条，就把它的内容写回剪贴板并**粘贴回用户原来打字的输入框**——全程不打断输入心流。托盘常驻，支持搜索、置顶、备注、更换呼出键、开机启动。

一句话的用户故事：我正在 A 应用里打字，复制了 B 应用里的一段内容，然后继续在 A 里打字；按呼出键，浮层出现在光标旁（A 的输入焦点没有被夺走），按 `↓↓Enter`，那段内容就粘贴进了 A 的输入框，浮层消失。

## 二、术语表

| 术语 | 定义 | 避免混用 |
|---|---|---|
| **历史条目（Entry）** | 一条被记录的复制结果，类型为文字或图片 | 记录、卡片、item |
| **条目身份** | 判定「两次复制是不是同一条」的唯一规则：只看内容 | 去重键、指纹 |
| **落位** | 条目在历史列表里的最终位置，由置顶状态与最近使用共同决定 | 排序 |
| **置顶块 / 普通块** | 列表两段布局：置顶条目的连续头部块 + 其后按最近使用的普通段 | 收藏区 |
| **置顶时间（pinnedAt）** | 最近一次置顶的时间戳；块内按它新→旧；未置顶为 0 | — |
| **来源应用** | 复制发生时前台应用的身份：可执行路径、应用名、窗口标题、图标 | — |
| **备注（note）** | 用户附加的可选单行文本，不参与条目身份；空串即无备注 | — |
| **面板** | 呼出的那个不可激活浮层 | 窗口、弹窗 |
| **呼出** | 按全局键让面板出现在光标处，**同时记录焦点快照** | 打开、显示 |
| **停靠（park）** | 面板「关闭」的实际动作：移到屏幕外驻留，不销毁窗口 | 隐藏、最小化 |
| **面板模式** | 显示期间的四种输入状态：浏览、搜索、备注编辑、捕获；后三者合称输入态 | 状态标志 |
| **呼出键 / 导航键** | 两类全局热键。呼出键常驻注册；导航键只在面板显示期间注册，集合由当前模式推导 | 笼统的「快捷键」 |
| **让位** | 某键从导航键集合退出、交还给输入框（如搜索态的空格/Z/Del/B） | 注销、禁用 |
| **焦点快照（focusTarget）** | 呼出时记下的前台窗口与焦点控件，粘贴回原输入框靠它 | 快照（泛指） |
| **捕获态** | 等待用户按下新呼出键的模式，期间其余热键全部让位 | — |
| **保持选中项可见** | 导航不变式：选中项任何时候完整落在**可视区**内 | 自动滚动 |
| **可视区** | 滚动口再让开上下各 10px 渐隐宽度的矩形；贴到滚动口边缘不算可见 | 视口 |
| **渐隐遮罩** | 列表上下边缘各 10px 的渐隐淡出，代替硬分割线 | 阴影、蒙版 |
| **复制并粘贴** | 完整动作：写剪贴板 + 注入回原输入框 | 复制（只指写剪贴板半步） |
| **注入** | 向已恢复焦点的原窗口发送粘贴键（如 Ctrl+V） | 粘贴 |
| **轮询基线** | 主进程「已见过的剪贴板内容」，判定下一轮轮询算不算新复制 | 缓存、快照 |
| **新复制** | 与基线不同、值得记进历史的剪贴板变化；自己刚写入的不算 | — |
| **结果契约（CopyResult）** | 复制并粘贴返回的 `{ ok, message }`，三入口共用 | 布尔成功标志 |
| **失败阶段（stage）** | `restore`＝没找回原窗口焦点；`paste`＝找回了但注入失败。文案不同，都决定面板保持显示 | — |
| **意图 / 事实** | 开机启动的两面：持久化的用户意图 vs 系统当前的实际状态 | 期望值/实际值 |

## 三、行为规格

### 3.1 剪贴板监听与记录

1. 周期性检查剪贴板（参考值 **600ms**）；若平台提供廉价的「变更序号」，序号未变时**不打开剪贴板、不读内容**，直接跳过本轮。
2. 剪贴板内容与**轮询基线**不同 → 是一次**新复制**，记进历史。程序自己刚写入的内容不算新复制（见 3.9 的基线同步）。
3. 记录文字与图片（PNG）。空内容不记录。图片持久化为独立文件（文件名＝条目 id），内容哈希只用于身份判定，不进文件名。
4. 同时记录**来源应用**：可执行文件路径、应用名、窗口标题、图标（dataUrl）。取不到时各字段允许为空，但不允许缺字段。
5. 单轮读取或写盘失败：本条不落库、**不更新基线**（下轮重试同一内容），单次异常只跳过本轮，不许拖垮轮询循环。
6. 历史变更（新增/提升/置顶/删除/备注/清空）＝一次原子提交：**先持久化，再广播**给渲染层。渲染层不直接改数组，只发命令、听事件。

### 3.2 条目身份与去重

1. 身份**只由内容决定**：文字按逐字符相等；图片按 PNG 内容哈希（参考实现用 sha1）。备注、来源、置顶、时间都是属性，不参与身份。
2. 复制了历史中已有的内容 → **不新建条目**，把命中的那条**提升**为最近使用：置顶条目刷新 `pinnedAt` 移到置顶块最前；普通条目移到普通块最前。其备注、来源、创建时间保持不变。
3. 命中多条重复时，按当前列表顺序取第一条，只提升该条，不合并其余。
4. **不自动清理**历史中已有的重复项（自动合并会丢用户备注），由用户手动删。
5. 「复制一条已有内容」与「在面板里使用一条已有内容」落位规则相同——用户看不出差别，这是刻意的。

### 3.3 落位：置顶块与普通块

1. 列表是两段布局：头部连续的**置顶块**（块内按 `pinnedAt` 新→旧）+ 其后的**普通块**（按最近使用新→旧）。
2. 新复制永远插在**置顶块之后、普通块最前**。
3. 插入位置只有一份算式，四个入口（新文字、新图片、去重提升、置顶切换）共用；出现第二份复制粘贴的实现即返工信号。

### 3.4 上限、裁剪与删除

1. 历史上限 **200 条**。裁剪只裁普通块尾部；普通块空了才裁最旧的置顶条目（**置顶豁免**只针对裁剪）。
2. 删除与清空**不豁免**置顶条目——置顶是排序优先级，不是保护锁。
3. 删除/裁剪图片条目时同步删除其图片文件，并失效该条的 dataUrl 缓存。

### 3.5 面板窗口

1. 尺寸参考值 **418×823**（DIP）。呼出时出现在**光标所在位置**（不超出所在显示器工作区）。
2. **不抢焦点**：呼出不激活面板；浏览态下键盘焦点仍留在原应用（键由全局热键拦截，见 3.7）。输入态（搜索/备注/捕获）临时聚焦面板，退出后归还。
3. 置顶（always-on-top）、透明背景、圆角（参考值 20px）。**圆角外的透明区域点击穿透**到下层窗口（按几何计算，不是整窗一个开关）。
4. **点击面板外任意处 → 隐藏**。需要全局点击监视来实现。
5. 「关闭」＝**停靠**：移出当前显示器工作区驻留，窗口对象不销毁（避免反复建窗的开销与焦点闪烁）。停靠时固定尺寸，防跨屏 DPI 漂移导致变形。
6. 每次呼出完成后发一次「面板已显示」事件，渲染层据此重置搜索态与选中项（**不**重新拉全量列表，避免闪烁；列表数据由实时广播维持）。

### 3.6 面板模式状态机

四个模式：`Browse`（浏览）、`Search`（搜索）、`NoteEdit`（备注编辑）、`ShortcutCapture`（捕获）；`composing`（输入法组合中）是 Search 的子态。

1. **热键集合由当前模式唯一推导**，与已注册集合做**差量同步**（只注册/注销需要动的键）。模式转换禁止各自手写 register/unregister——散布多处是本项目历史上真实付过学费的返工信号。
2. 呼出键：任何时候注册（捕获期间临时注销，值不变）。
3. 导航键八个：`↑` `↓` `Enter` `Esc` `Del` `Z` `B` `Space`。各模式下的注册集合：
   - Browse：八个全注册。
   - Search（非组合）：`↑↓ Enter Esc` 保持；`Space Z Del B` 让位。
   - Search（组合中）：导航键**全部暂停**，交给输入法。
   - NoteEdit / ShortcutCapture：导航键**全部让位**。
4. **呼出（show）**：置 visible＝true；若非捕获态则重置为 Browse、清 composing 与备注编辑；重算热键；广播「面板已显示」。
5. **隐藏（hide）**：按捕获→备注→搜索顺序逐层退出（同一时刻最多一个输入态，逐层只为发对退出事件），重算热键（只余呼出键），**消费焦点快照**；`restore_focus` 为真时把焦点归还原窗口。
6. **进入输入态的统一前置**：先互斥退出另一输入态（发对退出事件）；焦点快照缺失则**补拍**，失败则上报并放弃本次转换（呼出时补拍失败是静默的，面板照常显示）。
7. **焦点快照生命周期**归状态机：呼出时确保存在；同一次呼出内跨输入态**复用**（退出输入态归还焦点但快照保留，还能再进搜索）；隐藏时消费并清空。
8. `Esc`：Browse → 隐藏面板并归还焦点；Search → 先退回 Browse（不隐藏）。
9. 长按 `↑`/`↓` 连续移动：全局热键关闭了系统自动重复，需应用自行重复投递（参考实现：首按立即，300ms 后每 50ms），只对这两个键生效，面板隐藏后停止。
10. 状态机是纯逻辑：所有效果（注册热键、聚焦、发事件、拍/还原焦点）经效果宿主接口注入，转换与热键推导可整机单测（参考实现 12 例，见第八节）。

### 3.7 全局热键与让位

1. 热键分两类：**呼出键**（一个，可更换）与**导航键**（八个，集合随模式变）。
2. 注册失败（键被占用）必须可感知：换键捕获时据此判定失败并提示；普通注册失败写日志。
3. 让位是**规则**（从推导集合里移除），不是对已注册键的「禁用」——由差量同步注销实现。
4. 渲染层与主进程共用一个 accelerator 字符串协议（如 `Control+Shift+V`），由平台适配层翻译成系统可注册形式。

### 3.8 键位表

面板显示期间（全局拦截，非面板内 keydown）：

| 键 | 浏览态 | 搜索态 |
|---|---|---|
| `↑` `↓` | 选择（长按连续移动；首尾停住不环绕） | 在筛选结果里选择（同左） |
| `Enter` / 双击 / 复制按钮 | 复制并粘贴 | 同左 |
| `Esc` | 隐藏面板并归还焦点 | 先退回浏览态 |
| `空格` | 进入搜索态 | 输入空格 |
| `Z` | 置顶 / 取消置顶 | 让位给输入框 |
| `Del` | 删除条目 | 让位给输入框 |
| `B` | 编辑选中项备注 | 让位给输入框 |

1. 中文输入法组合期间面板导航键全部暂停（见 3.6.3）。
2. 上下移动在首尾**停住不环绕**；每次查询变化选中项重置到第一个匹配项；列表变短时选中项拉回有效范围。
3. 键盘导航把选中项滚到列表边缘时，滚到的是**渐隐遮罩内侧**（可视区），不是滚动口边缘；回到第一项时列表也回到呼出时的位置。
4. 搜索态下 `Enter` 复制的是**筛选结果里**当前选中的条目，不是原列表索引。

### 3.9 复制并粘贴（顺序契约）

「使用一条条目」是一条**固定顺序**链路，任何入口（键盘 Enter / 双击 / 复制按钮）共用：

```
取条目内容 → 写剪贴板 → 落位（提升 + 持久化 + 广播 + 同步轮询基线）
→ 取焦点快照 → 恢复原窗口焦点 → 注入粘贴键（Ctrl+V）→ 成功后隐藏面板
```

1. **落位必须在注入之前**：粘贴失败时内容确实已进剪贴板，列表仍要反映这次复制。
2. **隐藏必须在注入成功之后**，且隐藏时**不再重复恢复焦点**（焦点已由链路归还）。
3. **写剪贴板后必须同步轮询基线**，否则下一个轮询周期把刚粘贴的内容当新复制再提升+广播一次（症状：粘贴后列表闪一下、同内容两条）。
4. **绝不**向没恢复成功的窗口注入内容；**绝不**假报成功。
5. 失败两阶段，文案不同且单一来源：`restore`（没找回原窗口）／`paste`（找回了但注入失败）。失败时**面板保持显示**，发焦点错误事件；错误文案与结果契约的 `message` 同源（同一处代码产出两路）。
6. 三入口共用结果契约 `{ ok, message }`；成功路径由主进程收面板，渲染层再弹成功 toast。
7. 这条链路的**顺序与文案必须有自动化测试**钉住（参考实现：注入端口 + 记录调用顺序的假实现，9 例）。
8. 呼出面板时**先拍焦点快照再显示面板**，避免面板自己成为「原输入框」。

### 3.10 搜索

1. 参与匹配的五字段：正文（仅文字条目）、备注、来源应用名、窗口标题、可执行文件路径。
2. 大小写不敏感；空格分词、多词 **AND**；命中片段**高亮**（已命中的片段不被后续词二次切分）。
3. 结果**保持原顺序**（置顶块→最近使用），**不做匹配度排序**——可预测性优先，这是刻意决策。
4. 空查询＝不过滤。无匹配与全空历史是两种不同的空状态文案。

### 3.11 备注

1. 单行文本，上限 **200 字**；不参与条目身份；空串即无备注。
2. `Enter` 保存、`Esc` 取消、失焦保存；退出编辑态时若有未保存草稿先保存。保存失败有 pending 标记防状态错乱。
3. 备注参与搜索与高亮；列表内联编辑优先，详情面板编辑兜底。

### 3.12 更换呼出键（捕获流程）

1. 进入捕获态：注销呼出键与全部导航键（按键让位给要捕获的组合键），面板显示捕获覆盖层。
2. 捕获中按 `Esc` → 取消：恢复原呼出键与（面板仍显示时的）导航键，发 capture-end 事件收起覆盖层。
3. 捕获中按组合键：**必须包含 Ctrl/Alt/Win(Super) 之一**（仅 Shift 不合格），不合格就地提示。
4. 新键注册成功 → 换键成功，退出捕获态（不发 capture-end，覆盖层由渲染层自行收起），提示 1.2s 后收起；注册失败（被占用/无效）→ **保持捕获态**，提示「已被占用或无效，请换一个」。
5. 持久化的快捷键为空时归一化为默认值 `Control+Shift+V`。

### 3.13 托盘与开机启动

1. 托盘常驻，菜单四项：显示剪贴板面板 / 更换快捷键 / 开机启动（勾选态）/ 退出。
2. 托盘图标按目标平台的 HiDPI 规则提供恰当分辨率（Windows 参考：16/20/24/28/32 五档 × 亮暗两套，按主屏缩放系数取恰好物理尺寸那张 1:1 渲染，绝不让系统重采样；缩放变化时重选）。
3. **开机启动 = 意图/事实分离**：设置里持久化的是用户**意图**；系统实际状态（自启动项/任务是否存在）每次启动实测。未提权等暂时建不了事实的场景，先落盘意图、等有权限的会话补建——否则出现「打开→重启→变回关闭」。

### 3.14 主题与文案

1. 主题三态：浅色/深色/跟随系统，默认跟随系统；界面语言中文。
2. 时间显示相对化：刚刚 / N 分钟前 / N 小时前 / 「M月D日 HH:mm」。

## 四、数据契约

应用数据目录下三个文件（Windows 参考：`%APPDATA%\ClipboardTool\`）。**schema 与键名是已写在用户磁盘上的既成契约，改动必须兼容旧档**——这是本仓库翻过一次车的领域（键名大小写），规则：序列化键名显式指定，不依赖框架默认；旧键名留 alias 兼容；为键名写**往返序列化测试**。

**`clipboard-history.json`** — 条目数组，字段 camelCase：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 条目 id；图片文件名＝id |
| `type` | `"text"` \| `"image"` | — |
| `text` | string? | 文字条目内容 |
| `imagePath` | string? | 图片文件相对路径（文件创建后内容不变） |
| `createdAt` | number | 创建时间戳（毫秒） |
| `sourceApp` | object? | `{ exePath, appName, windowTitle, iconDataUrl? }`，各字段可空 |
| `pinned` | boolean | 置顶 |
| `pinnedAt` | number | 最近置顶时间戳，未置顶 0 |
| `note` | string | 备注，空串＝无备注 |

**`images/`** — 图片条目的 PNG，文件名＝条目 id；删除条目同步删文件。

**`settings.json`** — `{ "autoStart": bool, "shortcut": string }`，camelCase 键名不可改；解析任何情况下不报错，坏档退化为默认值并尽量手缝吸收已知键；空 `shortcut` 归一为默认。

**图片 dataUrl 缓存**：广播给渲染层时图片以 dataUrl 传输；dataUrl 按 `imagePath` **永久缓存**（文件创建后内容不变），删除/裁剪/清空时同步失效。不做缓存＝每次广播对每张图重编码，是参考实现实测过的最大性能坑（614ms/次）。

**主题偏好**存渲染层本地存储（key `clipboard-tool:theme`），不属于持久化契约。

## 五、UI 规格

面板为单窗口三段布局（自上而下），单页应用：

**标题栏（44px）**：居中「剪切板」标题＋计数（有筛选时显示「N 项 · M 总数」）；右侧两个图标按钮：主题切换（浅→深→跟随系统三态循环，图标随之）、清空历史（空历史时禁用）。

**搜索框**：常驻。非搜索态只读、占位「搜索剪切板…」，点击请求主进程进入搜索态；搜索态可输入，有内容时出现清空按钮。输入法组合事件上报主进程（暂停导航键）。

**历史列表**：标题行「复制项列表 / 搜索结果」＋「N 项」。条目卡从左到右：

- 来源图标（有来源图标显示图标；图片条目用图片图标兜底；点击开详情）；
- 主体：文字预览（空内容显示「（空内容）」，搜索态高亮命中）或图片缩略；meta 行＝相对时间（等宽数字）＋「已置顶」（置顶时）＋备注（有则显示，点击进编辑；编辑中就地变输入框，回车保存/Esc 取消/失焦保存，显示字数上限逻辑在底部快捷条）；
- 操作按钮组（悬停浮现）：置顶/取消置顶、备注、复制并粘贴、删除。

列表滚动：上下各 **10px 渐隐遮罩**代替硬分割线；留白必须大于渐隐宽度，且用**同源**的 scroll-padding 把这段留白声明成可视区（只靠 padding 不够——`scrollIntoView` 的 nearest 会把留白当多余空间滚掉，首尾卡片会淡成一道阴影；这条在本仓库翻过车，规则是「判定与留白同源，交给滚动系统执行」）。自定义细滚动条，滚动时出现、闲置约 900ms 隐藏。

**空状态**两种：无历史（「还没有剪切板内容 / 去复制一些文字或图片吧…」）；有历史但无匹配（「没有找到匹配 "xx" 的结果 / 试试换个关键词…」）。

**详情面板**（选中条目后展开）：返回按钮、类型徽章（文本/图片）、操作行（复制/置顶/删除）、内容预览区（文字或大图）、来源块（图标＋应用名＋窗口标题或路径）、备注区（点击编辑）、完整时间。浏览态默认不展开。

**底部快捷条**：按当前态切换——浏览态六键提示（Z 置顶 / DEL 删除 / 回车 复制 / B 备注 / ESC 隐藏界面 / 空格 搜索）；搜索态三键（ESC 退出搜索 / ↑↓ 选择 / 回车 复制）；备注编辑中显示「回车 保存 · Esc 取消 · N/200」；焦点错误发生时显示错误文案（优先级最高）。

**Toast**：约 2.4s 自动消失；成功「已复制并粘贴」「已删除」「历史已清空」；失败显示结果契约携带的文案（不另造文案）。

**快捷键捕获覆盖层**：模态卡片，显示当前键、示例提示、状态反馈（成功/失败文案）、取消按钮（Esc）。

**事件协议**（主进程 → 渲染层，全部经一个出口，窗口不在时静默丢弃）：历史变更广播（全量条目数组）、面板键动作（`{ action, noteEntryId? }`，值域：up/down/enter/delete/pin/escape/search-enter/search-exit/note-edit-enter/note-edit-exit）、面板已显示、焦点错误（`{ stage, reason, message }`）、捕获开始（带当前键）/捕获结束。

## 六、视觉设计语言

Apple 产品页语言的桌面化移植（「大留白的大教堂，巨字悬浮，靠粉彩与一条蓝线系住」）：

**Tokens**（浅色；深色对应 `#1d1d1f` 系 → `#2c2c2e/#3a3a3c` 卡片）：

| 语义 | 值 |
|---|---|
| Primary Ink（主文本） | `#1d1d1f` |
| Mid Gray（次要文本） | `#707070` |
| Deep Gray（工具按钮） | `#474747` |
| Hairline（唯一允许的边框） | `#d6d6d6` |
| Canvas（窗口画布灰带） | `#f5f5f7`（约 95% 不透明毛玻璃：blur 28px saturate 180%） |
| Paper（卡片/输入框） | `#ffffff` |
| Cool Wash（hover 底） | `#e8e8ed` |
| Faded Surface（抬升面板/标题栏毛玻璃） | `#fafafc`（blur 20px） |
| Quiet Dot（微弱指示） | `#777779` |
| Electric Blue（唯一彩色实心 CTA） | `#0071e3` |
| Link Blue（行内高亮/链接） | `#0066cc` |
| Ember（警示点缀） | `#b64400` |
| 来源应用色板（唯一彩色载体） | Sky `#c8d8e0` / Citrus `#dddc8c` / Starlight `#f0e4d3` / Silver `#e3e4e5` / Blush `#e8d0d0` / Indigo `#596680` / Midnight `#2e3642`，按来源应用名映射 |

**排版**：Display 级 600/700 字重负字距（-0.022em 级）；正文 13px/400（-0.08px）；微文案 11–12px；数字等宽（`numr` 或 tabular-nums）。行高 Display 1.04–1.07、正文 1.45。

**间距与圆角**：基准 4px；卡片 16px、大卡 28px、按钮全胶囊（980px）、输入 12px、窗口 20px；标题栏与底条圆角随窗口内缩 2px。分区靠 Canvas/Paper 交替，**不用实线分割、不用阴影**。

**动效**：只有 `transform`/`opacity`/`filter` 参与动画（几何属性不动，卡片待在合成层）；进出共用同一组弹簧参数、可中断不排队；悬浮反馈＝1px 抬升＋按压回弹，不放大不改色；系统「减少动态效果」与「降低透明度」两条设置下，过渡与 blur **全部彻底关闭**（不留残余动画，且不被后层覆盖压死）。

**Do / Don't**：Do—交替 #ffffff/#f5f5f7 成节奏、单区最多一枚实心 CTA、来源图标作唯一彩色载体。Don't—阴影（选中态只用 1px 内描边）、彩色点缀（蓝与色板外）、实线分割、渐变、圆角小于 8px、链接底盒。

**透明浮层的实现纪律**（参考实现逐像素验证过，跨框架依然成立）：透明窗口下 CSS 阴影/光晕按方角栅格化会楔出色块，聚焦态用**描边**替代；描边是框架唯一的亮线，贴它内侧**不放高光、不放滤镜**（否则叠出第二层边框）；分数缩放下贴窗口边缘的描边会被 alpha 裁掉，外层容器要留整数设备像素的内边距相位。

## 七、平台适配层（效果端口）

核心逻辑只依赖以下**端口接口**（平台无关语义 + 各平台参考）。实现时每个端口一个 adapter，测试时注入假实现。

| 端口 | 平台无关语义 | 参考实现 / 平台注意点 |
|---|---|---|
| 全局热键 | 注册/注销 `accel→action`；返回注册成败 | Windows `RegisterHotKey`（系统无自动重复，↑↓ 需自行重复投递）；**提权窗口的 UIPI 会静默拦截低完整性进程的热键与输入注入**，Windows 上必须定提权模型（见下） |
| 剪贴板 | 读/写文本与 PNG；查询变更序号 | Windows 变更序号短路未变化轮次；macOS NSPasteboard changeCount；Linux 各 WM 剪贴板管理器竞争 |
| 前台应用信息 | 取前台窗口的 exe 路径、应用名、窗口标题、图标 | Windows `SHGetFileInfo`/`ExtractAssociatedIcon`；macOS 需辅助功能权限 |
| 焦点快照/恢复 | 快照「前台窗口+焦点控件」；把焦点还原回去 | Windows 进程内 `GetGUIThreadInfo`/`SetForegroundWindow` 级联，等恢复用 4ms 步进轮询＋总预算超时，不写死 Sleep；恢复前先判「已在原位」零操作直返 |
| 输入注入 | 向目标窗口发送粘贴键 | Windows `SendInput`（**结构体布局是契约**，加编译期尺寸断言；失败不报 UIPI）；macOS CGEvent；Wayland 下基本不可行，需设计降级 |
| 浮层窗口 | 透明、圆角、置顶、**无激活显示**、按几何点击穿透、光标处定位、屏幕外停靠、多屏 DPI | Windows `WS_EX_NOACTIVATE`/`WS_EX_LAYERED`（组合会吃点击，需「可聚焦＋呼出不激活＋输入态临时聚焦」的组合拳）；macOS `NSPanel(nonactivating)`；穿透按圆角几何计算 |
| 全局点击监视 | 检测面板外点击 | Windows `WH_MOUSE_LL` 钩子（回调必须立即返回，不阻塞）；macOS 全局事件监听需权限 |
| 托盘 | 图标（按 DPI 取恰好物理尺寸）＋菜单 | 见 3.13；非整数缩放下单一基图必糊 |
| 开机启动 | 注册/注销自启动；意图/事实分离 | Windows 参考实现用计划任务（兼提权静默启动通道）；通用平台可用注册表 Run 项/launchd/XDG autostart |
| 提权模型（Windows 限定） | — | 三选一：**整应用提权＋计划任务静默启动**（本工具终选：manifest `requireAdministrator`＋`/rl highest` 计划任务，UAC 只在任务创建那一刻；dev 构建用 asInvoker）；Ditto 式按需提权；uiAccess=true（需签名，不现实）。选了常驻提权就不要再做提权提示 UI——「未提权」不再是用户可见状态 |
| 单实例 | 二次启动唤起既有实例 | — |
| 持久化 | 三个存档文件的读写 | 见第四节 |

## 八、架构与质量要求

1. **判定与效果分离**（本项目最高架构法则）：排序/去重/状态机/链路顺序/过滤/落位是**判定**，收敛为不依赖框架的纯模块，直测；剪贴板/落盘/窗口/热键/注入是**效果**，留在编排层或经端口注入。加代码前先问「这是判定还是效果」。
2. **深模块**：同一规则出现第三份复制粘贴就收敛成唯一实现。参考实现的收敛点清单，重实现时应一一对应：历史规则、面板模式状态机、模式入口（具名操作，不在调用方拼闭包）、面板窗口几何与 DPI 换算、轮询基线、粘贴链路、启动通道判定、键名契约、渲染层视图规则（过滤/高亮/选中项索引）。
3. **纯逻辑零框架 mock 单测**。参考实现 73 例的分布（作为覆盖面对照）：history 15 / panel_modes 12 / paste_chain 9 / poll_baseline 7 / settings 6 / startup 6 / panel_window 4 / 渲染层视图 14。panel_modes 的 12 例主题：呼出后注册全部导航键、搜索态部分让位与 IME 全暂停、退出搜索恢复集合并归还焦点且快照保留、Esc 的双语义、互斥退出与隐藏逐层退出、快照消费与不归还、呼出静默/输入态上报的快照失败差异、捕获换键成功/失败/取消三路、捕获中呼出不误注册、备注目标校验失败不进入、仅 ↑↓ 可重复。
4. **链路顺序用端口＋记录调用顺序的假实现钉住**，不是靠人盯。
5. mock 必须忠实（mock 窗口要真模拟几何变化，no-op mock 会让断言滑进回退分支假绿）。
6. 能收进类型/可见性/同源属性的约束，不要留在注释里（「靠注释维系的约束挡不住下一次改动」）。
7. 文档随行为同步；带日期的决策档案（ADR）记难回退的决策与被否决方案。

## 九、性能与诊断

1. 粘贴链路端到端目标 **<50ms**（参考实现从 ~1s 优化到位，三个根因值得背下来：每图重编码 → dataUrl 永久缓存；固定 Sleep → 步进轮询；基线未同步 → 重复提升）。
2. **优化前先分段测量**，不靠猜。
3. 提供诊断开关：运行期把呼出/复制/粘贴各阶段追加写诊断日志；轮询各阶段可追踪输出。GUI 子系统下 panic 默认不可见 → 统一落 panic 日志。

## 十、验收清单

每条行为规格都是验收项；以下是最容易被漏、且历史上真实翻过车的：

- [ ] 粘贴进管理员/提权窗口（Windows：这是最严苛且最常见的真实场景）
- [ ] 粘贴失败（restore / paste 两阶段）时：面板保持显示、文案正确、绝不假报成功
- [ ] 粘贴后列表不闪、同内容不记两条（基线同步）
- [ ] 来回复制两段文本不产生重复；复制已有内容只提升不新建
- [ ] 置顶块不被新复制插破；200 条裁剪时置顶豁免；删除不豁免置顶
- [ ] 搜索态：Space/Z/Del/B 打字不触发面板动作；IME 组合中方向键不误跳
- [ ] 长按 ↑↓ 连续移动，松开即停，首尾停住
- [ ] 滚到列表首尾，首尾卡片完整可见（不被渐隐遮罩压住）；回第一项时列表复位
- [ ] 圆角外点击穿透；点击面板外任意处隐藏
- [ ] 换键捕获：不合格组合就地提示、被占用保持捕获态、取消恢复原键
- [ ] 开机启动开关「打开→重启→仍打开」（意图/事实分离）
- [ ] 存档键名往返：保存→重载→字段不丢；坏档不崩溃、退化默认
- [ ] 非整数缩放档位（125%/150%/175%）：面板描边四边等宽贴边、托盘图标清晰
- [ ] 深/浅主题与「降低透明度」「减少动态」设置下的观感与动画彻底关闭

## 十一、已知平台坑速查（实现前必读）

完整版见原仓库 `docs/desktop-tool-pitfalls.md`，这里是重实现最常撞的十一条：

1. **UIPI（Windows）**：热键与输入注入对提权窗口静默失效，报错不指认真凶。设计期定提权模型，事后返工最大。
2. **`SendInput` 结构体布局（Windows）**：清理「未使用」的 union 成员 → 64 位下尺寸变化 → 全部注入报参数错误。关键结构体加编译期尺寸断言。
3. **透明窗口的阴影/光晕不可信**：按方角栅格化楔出色块；用描边替代；一切视觉结论以真机实测为准。
4. **`scrollIntoView` 会滚掉渐隐留白**（跨平台）：可视区判定用同源 scroll-padding 交给滚动系统。
5. **分数缩放下贴边描边被裁＋逐边取整不等宽（Windows web 系）**：整数设备像素的内边距相位对齐；描边内侧不放高光与滤镜。
6. **异步事件订阅的竞态**（跨平台）：订阅进挂载生命周期钩子，generation 计数防同 channel 双注册；导航类订阅常驻、回调走引用。
7. **输入模式用状态机**：四态＋推导热键差量注册；布尔堆与散布的注册/注销是返工信号。
8. **性能靠分段实测**：先量每段再优化；三大根因见第九节。
9. **序列化键名是持久化契约**（跨平台）：显式指定、alias 兼容、往返测试。
10. **「判不出来就不动作」**：命中测试/窗口状态拿不到时交空，调用方不据此隐藏面板。
11. **删实现时先看谁在守它**：守护测试没有等价物就先补，链路会当场裸奔。
