# 条目身份只由内容决定

一条历史条目「是不是另一条」只由内容判定：文字按文本逐字符相等，图片按 PNG 内容 sha1 相等。备注、来源应用、置顶（`pinned`/`pinnedAt`）、创建时间都是**属性**，不参与同一性判定。复制已在历史中的内容时不新建条目，而是把命中的那条提升为最近使用（置顶条目刷新 `pinnedAt` 移到置顶块最前，普通条目移到普通块最前），其备注/来源/创建时间保持不变。

## Considered Options

- **只比对最近一条**（原实现）：来回切换复制两段文本就产生 N 条重复，列表被同一内容刷屏。
- **每次复制都新建**：符合「操作日志」直觉，但剪贴板工具里同一串文本会被反复复制，历史迅速失去可读性。
- **自动合并历史中已有的重复**：会丢弃用户写在重复条目上的备注，改为只阻止未来产生新重复，已有重复由用户手动删除。
- 命中多条重复时按当前列表顺序取第一条，只提升该条、不合并其余。

## Consequences

- 「复制一条已有内容」与「按 Enter 使用一条已有内容」落位规则相同，用户看不出差别，这是刻意的。
- 图片条目文件创建后内容不变，因此按 `imagePath` 缓存 dataUrl 与哈希是安全的；条目被删除/裁剪时必须同步失效这两处缓存。
