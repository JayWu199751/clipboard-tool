# 复制并粘贴的顺序契约

「回车→粘贴」是一条固定顺序的链路：**取条目内容 → 写剪贴板 → 落位（提升 + 落盘广播 + 同步轮询基线）→ 取焦点快照 → 恢复原窗口焦点并注入 `Ctrl+V` → 成功后隐藏面板**。两条次序不能反：

- 落位在注入之前。粘贴失败时列表仍要反映这次复制，因为内容确实已经进了剪贴板；此时不隐藏面板、只发错误事件，绝不向没恢复成功的窗口注入内容。
- 隐藏在注入成功之后，且隐藏时不再重复恢复焦点（焦点已由粘贴链路归还）。
- 写剪贴板后必须同步轮询基线，否则下一个 600ms 轮询会把刚粘贴的内容当成新复制再提升+广播一次，表现为粘贴后列表闪一下。

## Consequences

- 三个入口（键盘 Enter / 双击 / 复制按钮）共用同一结果契约 `{ ok, message }`，失败路径假报成功是最伤信任的缺陷，所以文案与 `panel:focus-error` 事件必须同源（见 [desktop-tool-pitfalls.md](../desktop-tool-pitfalls.md) 第 2 节）。
- 这条链路由 `paste_chain` module 独占，顺序与文案由 9 例单测钉住；改任何一步之前先看它们。
- 呼出面板时先记录前台窗口/焦点控件再显示面板，避免面板自己成为「原输入框」。
