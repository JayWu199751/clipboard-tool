# 列表是「置顶块 + 普通块」两段布局

置顶条目形成列表头部的连续**置顶块**，块内按 `pinnedAt` 新→旧；新复制内容永远插在置顶块**之后**、普通块最前。置顶只是排序优先级，不是保护锁：删除与清空不豁免置顶条目，只有历史上限（200 条）裁剪时置顶块豁免——先裁普通块尾部，全是置顶时才裁最旧的那条置顶。

## Consequences

- 「插入位置」在四个入口（新复制文字、新复制图片、去重提升、置顶切换）必须走同一份算式，否则置顶块会被插破。这条规则的唯一实现是 `history.rs`，见 [architecture.md](../architecture.md)。
- 搜索结果的排序沿用同一套顺序，不做匹配度排序，因此筛选后的列表顺序可能与用户直觉不符，这是为可预测性付的价。
